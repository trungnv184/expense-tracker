## What was done
- `src/domain/csv.ts`: `toCsv` produces RFC 4180 quoting, rows sorted by date ascending, 2-decimal amounts, a UTF-8 BOM and CRLF line endings. `csvFilename` gives `expenses-YYYY-MM-DD.csv`.
- `SettingsPage`:
  - A currency select (8 currencies, default USD) with a live preview. It changes how amounts are displayed, never the stored values.
  - Export CSV, using a Blob download. No network calls.
  - The "Your data" notice.
- `expensesRepo.count()` supplies the expense count shown next to the export button.
- `playwright.config.ts` reads `PORT`, so e2e runs in parallel worktrees don't collide.

## Decisions
- The CSV uses category labels ("Living cost") rather than ids, and writes `true`/`false` for recurring. This reads better in a spreadsheet; the PRD doesn't specify either.
- A literal BOM character that slipped into the source was replaced with the `﻿` escape (ESLint no-irregular-whitespace).
- Built in a git worktree in parallel with M3-G3 and M4-G1 verification.

## Follow-ups / known limitations
- The network-silence check during export is part of M5-G2's network spec.
- AUD, CAD and SGD are formatted with en-US conventions.
