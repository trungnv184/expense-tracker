## What was done
- `BudgetsPage`: one amount field per category with Clear and "No budget" states. Saving validates every field, writes all changes in one transaction (`budgetsRepo.saveAll`), shows a toast and goes to the Summary.
- `BudgetGlance`: a desktop-only (≥ 1024 px) panel next to the expense list, reusing `BudgetBar` in compact form.

## Decisions
- The glance panel is driven by the whole month's expenses, so a category filter doesn't change it.
- E2E tests that seed IndexedDB directly reload the page, because Dexie live queries don't see writes made outside Dexie.
- While this was being verified, M4-G1 and M5-G1 were built in separate git worktrees so the verifier's working tree was never touched.

## Follow-ups / known limitations
- Months with no expenses show the empty state and no budget panel, as in the mockup.
