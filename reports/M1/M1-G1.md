## What was done
- Set up the Vite 5 + React 18 + TypeScript (strict) project. Tooling: Vitest + Testing Library + fake-indexeddb, Playwright (chromium) and ESLint 9 (flat config). Dexie, vite-plugin-pwa and axe-core are installed for later goals.
- npm scripts: dev, build, preview (port 4173), test, test:e2e, typecheck, lint, verify.
- Copied the mockup stylesheet into `src/styles/tokens.css` (design tokens) and `src/styles/base.css`. Mockup-only helpers were dropped.
- `AppShell`: top bar with a desktop nav (≥ 768 px), a mobile tab bar (< 768 px), a "+ Add expense" button and a mobile FAB. Hash router with every route from design §5, each showing a placeholder page.

## Decisions
- `tsc --noEmit` in a single tsconfig instead of project references. It's simpler, and Vite does the emitting.
- Nav active state uses NavLink's `.active` class, which matches the mockup's `aria-current` styling.

## Follow-ups / known limitations
- REQ-017's ≥ 1024 px two-column layout must be asserted once the Expenses and Summary pages have content (M2-G2, M3-G2, M5-G3). The verifier flagged this.
- Playwright `reuseExistingServer` could reuse a stale preview server. It will be turned off in M1-G2.
