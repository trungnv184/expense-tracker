Expense tracker · design draft

Every spend, one ledger.

A private web app for tracking Food, Education, Charity, Sport and Living cost, with monthly summaries, budgets, recurring costs and CSV export. These screens are static and clickable. Open any screen and use the “Requirements on this screen” note at the bottom to highlight what each element covers. Try them at phone width too.
